Notation key:
  n        scale degree  (1..7, 0 = rest), read against 1 = bB
  n/1      one underline  = eighth note
  n/2      two underlines = sixteenth note
  n/3      three underlines = thirty-second note
  n -      a dash after the number adds one beat (hold)
  n .      a dot after the number makes it dotted (x1.5)
  ^n / vn  octave dot above / below the number

Each line of the manuscript is written as: MELODY row, then BASS row.
