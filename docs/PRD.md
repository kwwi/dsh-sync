## 1. 产品定位与目标

**一句话**：用户输入生辰八字与姓氏等基本信息，系统推算命格喜忌，从中华经典文献中检索、筛选符合命格与音韵美感的汉字，生成带出处与解读的备选名字报告。

**参考范本**：[quming.txt](../quming.txt) 已定义输出结构与专业深度，产品应以此为「黄金样本」对齐报告质量。

**产品形态**：微信小程序（首期）；架构上预留 API 能力以便后续开放。

**服务对象**：
- **新生儿起名**：父母/长辈为主，强调吉祥寓意、家族偏好、重名规避。
- **成人改名/艺名/笔名**：本人决策，强调个人气质、职业场景、与原名衔接。

---

## 2. 用户角色与核心场景

| 角色 | 典型场景 | 核心诉求 |
|------|----------|----------|
| 父母/长辈 | 宝宝出生前/后起名 | 命格匹配、寓意好、好听、不重名、可解释给长辈听 |
| 成年人 | 改名、取艺名/笔名 | 改善运势感、职业形象、保留部分原名元素 |
| 分享对象 | 家人群转发报告 | 能看懂通俗结论，不必读完全部术语 |

### 3.1 信息采集（输入层）

**通用必填**：姓氏、性别、出生日期（公历/农历互显）、出生时辰、出生地点。

**场景差异**：新生儿（辈分字、兄弟姐妹名）；成人改名（现用名、改名原因、保留字）。

**偏好设置**：名字字数、风格标签、避讳字、五行策略。

### 3.2 八字命盘计算（确定性引擎）

四柱、藏干、十神、地势、刑冲、五行统计、真太阳时。LLM 不参与计算。

### 3.3 命格分析（LLM + 知识库）

专业层（可折叠）+ 通俗层（默认展开）；喜用神推导可追溯。

### 3.4 经典文献检索与选字（RAG）

P0 公版典籍；字义五行过滤；出处 100% 可溯源。

### 3.5 音韵规则（平仄押韵）

确定性引擎校验；v1.0 启用平仄过滤。

### 3.6 报告生成与展示

对齐范本结构；换一批、收藏、分享。

### 3.7 微信小程序特有需求

微信登录、合规声明、订阅消息、30～60 秒报告生成。

### 3.8 管理后台（运营期）

语料管理、Prompt 版本、反馈与监控。

## 4. 非功能需求

准确性、可解释性、幻觉控制、隐私、合规、可用性、扩展性。
