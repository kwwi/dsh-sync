## 版权原则

| 类别 | 使用策略 |
|------|----------|
| **公版古籍**（著作权人去世 50 年以上，中国境内通常视为公版） | ✅ P0 直接入库、全文索引 |
| **现代校注本** | ⚠️ 仅用古籍原文；校注、译文须用自研或公版白话 |
| **现代出版物**（余秋雨散文等） | ❌ MVP 不入库 |
| **网络语录 / 鸡汤** | ❌ 禁止 |
| **用户生成内容** | ❌ 不作起名出处 |

**出处展示格式**（强制）：
```
书名 · 篇章 · 原文句子
```
禁止仅写「古语有云」等不可溯源表述。

## 特殊文献处理

### 《符瑞图》

范本「景风」引用《符瑞图》，属古代瑞应文献，多散佚。处理：

- 不入全文库
- 在「景风」词条建立**人工策展条目**，关联《尚书·大传》《列子·汤问》等可溯源出处
- 产品展示合并为一条出处链，主出处优先《列子》或《尚书》系

### 编选本（如《唐诗三百首》）

- **诗文原文**：公版，可索引
- **编选者序、评注**：清代编选者评注若不足 50 年需甄别；默认不索引评注，仅索引诗正文
- **现代出版社前言**：❌ 不索引

## 语料数据结构

每条语料记录：

```json
{
  "id": "zhongyong-001",
  "book": "中庸",
  "chapter": "第一章",
  "original": "天地之道，博也，厚也，高也，明也，悠也，久也。",
  "vernacular": "君子修养取法天地之道……",
  "chars": ["博", "厚", "高", "明", "悠", "久"],
  "tags": ["儒雅", "大气"],
  "gender_hint": "neutral",
  "copyright": "public_domain",
  "source_edition": "四库全书本（公版）"
}
```

## 检索与索引策略

| 阶段 | 技术 | 说明 |
|------|------|------|
| MVP | 关键词 + 五行标签过滤 + 向量检索 | 小语料可单机 |
| v1.0 | 混合检索（BM25 + embedding） | 支持风格标签、性别意象 |
| 质检 | 出处回查 | 生成名字中的每字须在原文 `chars` 中出现 |

---

## 语料禁止清单

- 带有负面含义的章节（刑杀、丧葬、贬谪）→ 标签 `exclude_naming`
- 政治敏感内容 → 审核过滤
- 宗教典籍争议章节 → MVP 不纳入（佛教道教典籍放 P2）
