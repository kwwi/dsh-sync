# 决策记录：姓名学五行归属流派

**状态**：已确认  
**日期**：2026-06-25  
**关联 PRD**：§8 关键决策点 #1、§3.4 选字规则

---

## 背景

中文姓名学中，单字五行归属存在多种流派，直接影响「喜用神 → 选字」链路。范本 [quming.txt](../../quming.txt) 采用**字义五行**（如「明悠：火」「景风：火、木」），产品默认策略须与此对齐。

---

## 流派对比

| 流派 | 判定依据 | 优点 | 缺点 | 范本是否采用 |
|------|----------|------|------|--------------|
| **字义五行** | 汉字本义、部首意象 | 与典籍出处、寓意解读一致；用户易理解 | 一字多义时有争议；需人工/知识库维护 | ✅ 是 |
| **笔画五行** | 康熙笔画尾数 1～5 对应五行 | 规则统一、可自动化 | 与寓意脱节；同字简繁笔画不同 | ❌ 否 |
| **读音五行** | 声母韵母归属 | 与音韵模块协同 | 姓名学主流少用；争议大 | ❌ 否 |
| **部首五行** | 偏旁部首 | 与字义有交集 | 形声字部首不代表字义 | 部分参考 |

---

## 决策结论

### 主策略：字义五行为准（Primary）

- 选字、过滤、报告标注均以**字义五行**为唯一判定标准。
- 与范本输出格式一致：`[五行属性] 明悠：火`。
- 数据来源：自建「汉字五行属性库」，每条记录含：
  - `char`：汉字
  - `element`：木/火/土/金/水（主属性）
  - `secondary_element`：次要属性（可选，如「景」木、「风」水但整词取火木）
  - `source`：判定依据（字义出处、康熙字典释义摘要）
  - `confidence`：high / medium / disputed
  - `dispute_note`：争议说明（展示给运营审核，不默认展示用户）

### 辅助策略：笔画五行仅作参考（Secondary，v1.0 可选展示）

- 在报告「高级详情」中可选展示笔画五行，标注「传统姓名学参考，与主推荐无关」。
- **不参与**选字过滤与喜用神匹配。
- 避免两套标准打架导致用户困惑。

### 词组级五行（Name-level）

- 双字名可标注整体五行组合，如「景风：火、木」。
- 规则：逐字取主属性去重；若两字合成专有意象（成语、典故），以合成意象为准并覆盖单字（如「庭奕」取自「门庭赫奕」，标注土、火）。

## 喜用神匹配规则

```
输入：喜用神列表（如 [火, 木]），候选名字逐字五行
规则：
  1. 名字中至少 1 字主属性 ∈ 喜用神 → 通过
  2. 名字中无喜用神字，但有「生喜用神」属性（木生火） → 次优通过，报告中标注「间接补益」
  3. 名字含忌神属性且占比主导 → 过滤（用户选「严格喜用神」时）
  4. disputed 属性的字：MVP 阶段不进入候选池
```

**生克关系**（用于次优匹配与解读文案）：

| 五行 | 生 | 克 |
|------|----|----|
| 木 | 火 | 土 |
| 火 | 土 | 金 |
| 土 | 金 | 水 |
| 金 | 水 | 木 |
| 水 | 木 | 火 |

## 汉字五行库建设

### MVP 目标规模

- 覆盖 P0 语料中出现的全部汉字（预估 8,000～12,000 字）
- 常用起名字优先（GB2312 一级字表中与典籍交集部分，约 3,500 字）

### 标注流程

1. **自动初标**：部首 + 开源字典释义 → LLM 辅助分类
2. **规则校验**：金旁、木旁、水旁等明显部首走规则
3. **人工抽检**：争议字（confidence=disputed）人工裁定
4. **版本管理**：`wuxing_dict_v1.json`，变更有 changelog

### 争议字处理示例

| 字 | 常见归属 | 处理 |
|----|----------|------|
| 明 | 火（日光） | 主火，high |
| 庭 | 土（庭院） | 主土，high |
| 乾 | 金/天 | disputed → 运营裁定，默认金 |
