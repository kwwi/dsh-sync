# 微信小程序合规文案与类目申请

**状态**：已起草  
**日期**：2026-06-25  
**关联 PRD**：§3.7 微信小程序特有需求、§4 非功能需求（合规）

---

## 1. 推荐服务类目

| 优先级 | 类目路径 | 说明 |
|--------|----------|------|
| **首选** | 工具 → 信息查询 | 传统文化知识查询、姓名寓意解读 |
| 备选 | 生活服务 → 综合生活 | 若信息查询审核要求补充资质 |
| 避免 | 宗教 / 迷信占卜 | 不得宣称「改命」「预测未来」 |

**ICP 备案**：服务器在国内须完成备案，域名与小程序主体一致。

**若涉及付费**：需开通微信支付，类目可能需补充《增值电信业务经营许可证》咨询（按次报告通常按工具类目处理，以微信审核为准）。

## 2. 用户可见免责声明

### 2.1 首页底部（常驻）

```
本小程序基于中国传统文化的姓名学、五行学说及经典文献，提供姓名寓意参考与文学出处检索服务。

· 报告内容仅供文化学习与家庭参考，不构成命理预测或人生决策建议
· 起名结果不承诺任何运势、健康、事业等方面的效果
· 涉及出生时间等个人信息，仅用于生成报告，详见《隐私政策》
```

### 2.2 报告页顶部（每次生成展示）

```
【温馨提示】本报告由传统文献与智能技术辅助生成，喜用神分析及名字建议仅供参考，请结合家庭意愿与实际情况选用。
```

### 2.3 命格分析模块旁注

```
以下分析基于生辰八字的传统解读体系，不同流派结论可能存在差异。
```

### 2.4 支付页（v1.0 起，若启用）

```
您购买的是起名报告生成服务，非占卜或改运服务。虚拟内容一经生成，不支持退款（法律另有规定除外）。
```

## 3. 禁止宣传用语

审核与用户文案中**不得出现**：

| 禁止 | 替换为 |
|------|--------|
| 算命、占卜、改命、转运 | 传统文化参考、寓意解读 |
| 保证财运/姻缘/健康 | 文化寓意、典籍出处 |
| 大师亲算、祖传秘法 | 智能辅助、典籍检索 |
| 100% 准确、必有好运 | 供您参考、结合个人意愿 |
| 化解灾祸、挡煞 | （删除） |

---

## 4. 隐私政策要点

须单独页面，至少包含：

1. **收集信息**：姓氏、性别、出生日期时辰、出生地点、微信 openid、可选偏好设置
2. **使用目的**：生成起名报告、改进服务质量
3. **存储期限**：账号存续期间；用户注销后 30 日内删除
4. **加密**：出生信息 AES 加密存储，传输 HTTPS
5. **第三方**：LLM 服务商（通义/DeepSeek 等）仅接收脱敏后的结构化命盘，不传输 openid
6. **用户权利**：查询、导出、删除个人数据（小程序「设置 → 隐私」入口）
7. **未成年人**：14 周岁以下须监护人同意（新生儿起名场景常见，须勾选确认）

---

## 5. 用户协议要点

1. 服务性质：文化信息参考工具
2. 内容免责：典籍引用已尽力溯源，不排除标点/版本差异
3. 知识产权：报告仅供个人使用，不得商用批量生成
4. 违规处理：滥用接口、传播违法违规内容将封号

## 6. 微信审核材料清单

| 材料 | 说明 |
|------|------|
| 营业执照 | 经营范围含「信息技术服务」或「文化创意」等 |
| 小程序名称 | 避免「算命」「改运」字样；建议「XX起名」「XX名典」 |
| 简介 | 强调经典文献起名、文化寓意 |
| 服务页面截图 | 首页、输入页、报告页、免责声明可见 |
| 隐私政策链接 | 已发布的可访问 URL |
| 用户协议链接 | 同上 |
| 测试账号 | 供审核人员体验完整流程 |

## 7. 内容安全策略

### 7.1 生成前过滤

- 姓氏敏感词检测
- 避讳字用户自定义

### 7.2 生成后审核

- 名字谐音负面词库（普通话）
- 微信 `msgSecCheck` 文本安全接口（报告全文）
- 不通过则重新生成或人工复核队列

### 7.3 用户举报

- 报告页「反馈问题」入口
- 24 小时内处理违法违规举报

## 8. 订阅消息合规文案

**模板名称**：报告生成完成通知

```
您的起名报告已生成完成，点击查看备选名字与典籍出处。
```

不得包含「运势」「吉凶」等措辞。

## 9. 分享卡片文案

```
【起名参考】为{姓氏}宝宝精选了{ N }个出自经典的名字，附典籍出处与寓意解读。
```

分享图不得出现「八字」「改命」等敏感字样，可用「传统文化」「经典出处」。
