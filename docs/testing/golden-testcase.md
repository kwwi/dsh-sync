## 3. 排盘引擎预期输出（确定性）

### 3.1 时间换算

| 项目 | 预期值 | 容差 |
|------|--------|------|
| 北京时间 | 1988年1月12日 17:55 | 精确 |
| 真太阳时 | 1988年1月12日 16:50 左右 | ±2 分钟（经度实现差异） |
| 农历 | 丁卯年十一月廿三日 | 精确 |
| 时辰 | 申时（15:00–17:00） | 精确 |

> 说明：真太阳时 16:50 落在申时，与范本一致。

### 3.2 四柱八字

| 柱 | 天干 | 地支 | 干支 | 十神（相对丙火日主） |
|----|------|------|------|----------------------|

| 日 | 丙 | 寅 | 丙寅 | 日元 |
| 时 | 丙 | 申 | 丙申 | 比肩 |

**断言**：`年柱=丁卯, 月柱=癸丑, 日柱=丙寅, 时柱=丙申`

## 4. 命格分析预期（LLM / 规则，方向性校验）

### 4.1 喜用神

| 优先级 | 五行 | 必须通过 |
|--------|------|----------|
| 第一喜用 | **火** | ✅ |
| 第二喜用 | **木**（生火） | ✅ |
| 忌神 | 不应推荐以水、金为主导的名字（严格模式） | ✅ |

### 4.2 通俗结论（语义包含即可）

必须包含以下要点（关键词匹配或人工评审）：

- [ ] 五行不缺
- [ ] 优先考虑火属性名字
- [ ] 其次考虑木属性名字
- [ ] 语言通俗，非专业人士 30 秒内可理解

### 4.3 专业层（v1.0 起验收）

- [ ] 提及寅申相冲
- [ ] 提及丙火冬季休、宜调候
- [ ] 提及丙寅长生

## 5. 起名输出预期

### 5.1 格式检查（每个备选名）

- [ ] 完整姓名以「侯」开头
- [ ] 双字名（侯 + 2 字）
- [ ] 含典籍出处（书名 + 原文片段）
- [ ] 含白话释义
- [ ] 含 `[五行属性]` 标注
- [ ] 含拼音
- [ ] 出处可在 P0 语料库中回查

### 5.2 五行合规（严格喜用神模式）

每个备选名至少满足其一：

- [ ] 名中一字主五行为火
- [ ] 名中一字主五行为木
- [ ] 报告标注「间接补益」且经生克规则校验

### 5.3 范本参考名（非强制相同，供人工对比）

| 名字 | 出处 | 五行 | 说明 |
|------|------|------|------|
| 侯明悠 | 《中庸》 | 火 | 范本 #1 |
| 侯景风 | 《符瑞图》/《列子》等 | 火、木 | 范本 #2，符瑞图走策展条目 |
| 侯庭奕 | 门庭赫奕 | 土、火 | 范本 #3，含土但含火 |

> 自动化测试**不要求**生成与范本完全相同的名字，但人工评审时可对照质量。

### 5.4 音韵（v1.0 起）

- [ ] 每字标注平仄
- [ ] 给出音韵评价（至少 1 句）
